## Лабораторная работа №1
1) dotnet build собирает проект, но не запускает. dotnet run обычно собирает и запускает его.
2) В bin/Debug/net10.0/ появляются сборка .dll, файлы настроек и зависимостей, а также отладочные данные .pdb. Набор зависит от проекта и системы.
3) C#-код компилируется в IL, а при запуске JIT переводит его в машинные инструкции для процессора .pdb помогает отладчику находить ошибки и связывать выполняемый код со строками исходника.
4) .gitignore исключает из Git ненужные файлы, обычно bin/ и obj/.
5) Типы: фамилия — string, возраст — int, средний балл — double, признак отчисления — bool.
6) Environment.ProcessorCount показывает число доступных приложению логических процессоров. Оно зависит от компьютера и среды запуска.
7) Console.ResetColor() возвращает стандартные цвета консоли.
